<p>第一项是地区识别。方法很直接：连一次，让对方回显它看到的出口位置，再和你选的地区对照。多测几次看是否漂移。这一项反映出口属性是否如宣称，是最基础的检查。</p>

<p>第二项是稳定性。间隔一段时间反复连接，看结果是否一致、有没有莫名中断。单次成功不算数，连续多次都在同一状态才算过关。稳定性最怕以偏概全，样本多一点结论才可靠。</p>

<p>第三项是并发能力。在合规前提下做小样本的受控测试，观察同时发起多个连接时的表现。注意别把测试变成压力攻击，控制在允许范围内。记录实际表现再和宣称对比。</p>

<p>第四项是计费口径。评测不只是测性能，也要测透明度：并发怎么定义、流量怎么算、超额怎么处理。把这些问清楚并写进记录，是评测里同样重要的一半。</p>

<p>第六项是文档与说明的清晰度。供应商有没有把参数和限制讲明白，本身就能说明不少问题。文档含糊、要反复追问才能得到答案的服务，后面出问题时沟通成本往往也高。这一项虽软，却值得记一笔。</p>

<p>第五项是售后与变更。出口被重新调度时会不会通知、问题响应如何，这些也属于评测范围。性能再好，出了问题找不到人，实际体验也会打折。</p>

<p>还要说明对照组的设置。评测最好有个参照，比如同一时间用不同服务各测一轮，看差异在哪。没有对照，单次结果很难说明好坏。有了参照，结论才更有说服力，也更能反映真实差距。</p>

<p>怎么避开营销话术？一个办法是只认可复现的结果。评测时把步骤和条件写下来，别人照着做也能得到类似结论。凡是只给结论、不给方法的评测，都要打个折扣看。</p>
